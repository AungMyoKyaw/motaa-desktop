# MOTAA feature expansion

Mode: Operate. Extend the existing desktop chart workbook for astrologers. The user approved all eleven recovered modes and the advertised ZarTarPro capabilities, English interface/digits, source syllables, four theme families and the recommendations recorded in IMPLEMENTATION_PLAN.md.

## Direction contract

THESIS: The active profile, calculation settings, chart mode and time must remain understandable while moving among dense analysis views.

OWN-WORLD: Preserve DESIGN.md's cream/gold paper surfaces, quiet rules, traditional geometric charts, Helvetica Neue interface and source script notation. Pink, blue and monochrome are source-derived theme variants.

STORY: Choose a tool, inspect its chart/table, adjust a meaningful reference, then return to the profile or another analysis. Library and recovery workflows make destructive and importing operations reviewable.

FIRST VIEWPORT: 1440 × 960 canvas, 208 px navigation rail, 60 px native header, calculation context above chart/table workspaces, optional 98 px time footer. All tools is a directory of eleven recovered modes and sixteen advanced workspaces. Each module gets a content-specific layout.

FORM: Established-world extension following the user's approved questionnaire; no new identity or concept seed. Native FigCraft geometry/text and transparent navigation hotspots, with an offline image-based review gallery.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## Boundaries

This delivery extends the design. Editable form logic, persistence, numerical engines, historical timezone resolution, ephemeris/eclipses and interpretation sources are subsequent application implementation. Illustrative diagrams/data must not be described as calculated or numerically verified. All fifty-eight 1440 × 960 exports are required review evidence; smaller-window reflow is not established. Existing design.json drift predates this task and is not repaired.
